# Data Availability

## Public Materials

The repository is intended to provide analysis source code, validated processing parameters, software-environment specifications, metadata and feature schemas, synthetic/example inputs, publication-safe aggregate results, and reproducibility documentation.

## Restricted Materials

Raw participant videos are not included in the public repository because video may directly identify human participants. Participant-level metadata, event annotations, and derived data should not be released publicly unless release is explicitly permitted by the applicable consent, IRB/ethics approval, institutional policy, and privacy requirements.

## Suggested Availability Statement

> Source code, processing parameters, data schemas, example inputs, and reproducibility documentation are available through the associated public software repository. Raw participant videos and other potentially identifiable research data are not publicly distributed because of participant privacy and research-ethics restrictions.
