# Analysis Scripts

The public codebase uses stable descriptive filenames rather than development-version suffixes.

| Script | Role |
|---|---|
| `extract_pose.py` | Frame-level MediaPipe pose extraction |
| `extract_features.py` | Pitch-level event localization and biomechanical feature extraction |
| `quality_control.py` | Measurement quality control |
| `relative_mechanics.py` | Pooled and within-pitcher relative mechanical characterization |
| `prepare_analysis_data.py` | Deterministic model matrix construction, PCA, and primary K-means analysis |
| `cluster_analysis.py` | Initialization, participant-omission, balanced-resampling, and feature-domain robustness analyses |
| `mechanical_profiles.py` | Dataset-relative mechanical profile construction |
| `merge_analysis_outputs.py` | Strict unique-key merge of independent analytical pathways |
| `manual_event_annotator.py` | Blinded manual event annotation utility |
| `manual_event_annotator_holdout.py` | Independent holdout event-annotation utility |
| `validate_events.py` | FFC and release timing agreement analysis |
| `characterize_clusters.py` | Aggregate biomechanical cluster characterization |
| `feature_holdout_analysis.py` | Relative-mechanics feature-holdout clustering |
| `pitcher_adjusted_analysis.py` | Pitcher-adjusted cluster relevance analysis |
| `within_pitcher_clustering.py` | Within-pitcher-normalized clustering |
| `null_bootstrap_analysis.py` | Null-model and pitcher-stratified bootstrap analysis |
| `preprocessing_robustness.py` | Kinematic-smoothing sensitivity with feature, PCA, and cluster-agreement summaries |
| `quality_stratified_robustness.py` | Representation robustness across all-analyzable, QC-pass, and high-confidence observation strata |
| `analysis_utils.py` | Shared utilities for secondary analyses |
| `run_pipeline.py` | Raw-video orchestration through relative mechanical characterization |

## Study analysis order

```text
run_pipeline.py
    -> prepare_analysis_data.py
    -> cluster_analysis.py
    -> mechanical_profiles.py
    -> merge_analysis_outputs.py
    -> secondary analyses as required
```

The relative mechanical and clustering pathways are generated independently and integrated only after each path is complete. Downstream clustering analyses should use the model-ready table generated by `prepare_analysis_data.py`; this table contains the fixed 32-feature study matrix plus non-model metadata used for joining and reporting.



## Representation-robustness analyses

### Preprocessing robustness

`preprocessing_robustness.py` reuses existing pose CSVs and reruns feature extraction under alternative kinematic smoothing windows while leaving the validated event-localization settings fixed.

Default run:

```bash
python scripts/preprocessing_robustness.py \
  --pose-dir outputs/pose \
  --metadata metadata/pitch_metadata.csv \
  --windows-ms 50 100 200 \
  --reference-window-ms 200 \
  --output-dir outputs/preprocessing_robustness
```

Primary outputs:

```text
outputs/preprocessing_robustness/
├── condition_summary.csv
├── feature_agreement_vs_reference.csv
├── representation_agreement_vs_reference.csv
├── analysis_manifest.json
├── 50ms/
├── 100ms/
└── 200ms/
```

The comparison reports feature-level correlation and error, PCA Procrustes disparity, selected cluster count, silhouette, and ARI relative to the reference smoothing condition.

### Quality-stratified robustness

`quality_stratified_robustness.py` reruns the primary representation analysis in increasingly strict measurement-quality subsets.

Default run:

```bash
python scripts/quality_stratified_robustness.py \
  --input outputs/features/pitch_features_qc_annotated.csv \
  --output-dir outputs/quality_stratified_robustness
```

Primary outputs:

```text
outputs/quality_stratified_robustness/
├── stratum_counts.csv
├── stratum_summary.csv
├── representation_agreement_vs_all_analyzable.csv
├── analysis_manifest.json
├── all_analyzable/
├── qc_pass/
└── high_confidence/
```

By default, the high-confidence stratum requires pose-detection rate ≥0.95, minimum critical-landmark visibility ≥0.75, FFC and release confidence ≥0.70, critical raw gaps ≤50 ms, an event window between 50 and 500 ms, and no FFC fallback detection. These thresholds are configurable and are used only for robustness analysis; they are not clinical thresholds and do not replace the validated study QC.

See [`../docs/reproducibility_check.md`](../docs/reproducibility_check.md) for the regression comparison against the archived study outputs.
